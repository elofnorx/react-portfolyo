# Elifnur Bağcı | Eğitim Teknolojileri Portfolyosu

Hacettepe Üniversitesi BÖTE öğrencisiyim. Uygulamalı kodlama eğitimi, öğretim tasarımı ve dijital öğrenme araçları üzerine çalışıyorum.

[Portfolyo sitesi](https://react-portfolyo-red.vercel.app/)

## Seçili projeler

| Proje | İçerik | Bağlantılar |
| --- | --- | --- |
| Bilişim Macerası / Robi’nin Macerası | Özel eğitimde fare ve klavye becerileri için 40 oyun tabanlı etkinlik ve öğretmen paneli | [Demo](https://elofnorx.github.io/bilisim-macerasi/) · [Kaynak kodu](https://github.com/elofnorx/bilisim-macerasi) |
| RoboKâşifler (RoboCraft) | Tinkercad ve Arduino için uzaktan eğitim portalı | [Demo](https://robocraft-aue.vercel.app/) |
| AKORD | C# algoritma öğreniminde yapay zekâ desteği üzerine araştırma prototipi | [Demo](https://akord-sage.vercel.app/) |

## Yerel geliştirme

```sh
npm ci
npm run dev
npm run lint
npm run build
```
